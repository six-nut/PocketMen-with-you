# Privacy, rights and IP guidance

- Treat personal photos as private inputs. Do not add them to Git, README examples, issues, release files or telemetry.
- Generated pet assets may still reveal a person's or pet's appearance; only publish them when the user explicitly wants that.
- Do not ask users to paste secrets into chat.
- Use the project's original companion-capsule branding for generic monster/creature modes.
- Do not market this project as affiliated with Nintendo, The Pokémon Company, Game Freak, OpenAI or GitHub.
- Users should have rights/permission for reference images and requested character material.
